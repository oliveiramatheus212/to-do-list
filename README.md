# 📝 Simple To-Do List App (Vue 3)

This is a simple and lightweight To-Do List web application built with [Vue.js 3](https://vuejs.org/) that allows users to manage their daily tasks. Tasks are stored locally using the browser's `localStorage`, so your list is saved even if you refresh or close the browser.

## 🚀 Features

- ✅ Add new tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as complete/incomplete
- 💾 Persistent storage with `localStorage`
- ⚡ Fast and responsive UI with Vue 3

## 🛠️ Tech Stack

- [Vue.js 3](https://vuejs.org/)
- HTML5 & CSS3
- JavaScript (ES6+)
- Local Storage API
